# 行迹 DayTrail 隐私政策

> 生效日期：2026-01-01
> 适用版本：0.4.0 及以后
> 政策地址：<https://github.com/hmilyld/daytrail/blob/main/docs/privacy-policy.md>
>
> 应用内「我的 → 隐私与合规」展示的是本政策的**摘要**；完整版本以本文件为准。

## 一、我们处理哪些信息，为什么

| 信息类型 | 具体内容 | 处理目的 | 是否离开设备 |
|---|---|---|---|
| 精确/粗略定位 | 经纬度、时间戳、定位精度、速度、方向 | 记录轨迹、计算里程与停留 | **否**（默认全部本地） |
| 后台定位 | 应用不在前台时采集的位置 | 持续记录轨迹 | **否** |
| 轨迹纠偏请求 | 若干轨迹点的坐标、速度、方向、时间 | 用户点「补全路线」时把轨迹贴合路网 | **是**，发送至高德 Web 服务 |
| 地点名反查请求 | 一个地点的坐标 | 新建地点或点「补全名称」时取名 | **是**，发送至高德 Web 服务 |
| 地图渲染 | 由高德地图 SDK 自行采集的设备标识、网络状态、WiFi 信息、粗略位置 | 加载与缓存地图瓦片 | **是**，由高德 SDK 发送至高德服务器 |
| 诊断日志 | 状态变化文本（如「进入休眠」），**不含坐标** | 排查「为什么没有采到点」 | **否**（仅用户手动导出时） |
| 更新检查 | IP 地址、User-Agent、当前版本号 | 判断是否有新版本 | **是**，发送至 GitHub |

### 我们不处理

剪贴板、通讯录、通话记录、短信、相册、通话状态、IMEI/设备序列号、
账号信息、支付信息、广告标识符。应用**没有账号体系，也没有自建服务器**。

### 关于行踪轨迹

行踪轨迹属于《个人信息保护法》定义的**敏感个人信息**。因此：

- 我们在开始记录之前**单独向你告知并单独征得同意**（引导页的独立勾选项）；
- 拒绝或撤回该同意不影响你查看已导出的数据，但记录功能将不可用；
- 你可以随时在「我的 → 隐私与数据」撤回同意。

## 二、信息如何存储

- 所有轨迹数据存放在应用的私有目录（Room 数据库），其他应用无法读取。
- 设备使用 Android 的文件级加密（FBE），关机状态下数据不可解密。
- 应用明确**关闭**了云备份与设备迁移备份（`allowBackup=false`），
  数据不会进入 Google 云备份或其他设备的迁移包。
- 没有服务端留存：我们**没有**服务器，也就没有服务器侧的数据副本。

## 三、信息如何共享

我们不出售、不出租、不以营销为目的共享你的个人信息。仅在以下情形数据会离开设备：

1. **高德地图 SDK** —— 加载地图瓦片时的设备与网络信息，由 SDK 直接发往高德服务器。
   高德隐私政策：<https://lbs.amap.com/home/privacy>
2. **高德 Web 服务** —— 你主动触发的轨迹纠偏与地点名反查，只发送相关坐标。
3. **GitHub** —— 检查更新时发送 IP、UA 与版本号，由 GitHub 记录访问日志。
   GitHub 隐私声明：<https://docs.github.com/site-policy/privacy-policies>
4. **应用分发渠道** —— 你从何处下载本应用（如 GitHub Releases），该渠道可能记录下载行为，
   这与本应用无关。

## 四、你的权利

| 权利 | 操作方式 |
|---|---|
| 查阅 | 「历史」页查看每天的轨迹与停留；「行程」页查看归并后的行程 |
| 复制/导出 | 「我的 → 数据 → 导出」，支持 GeoJSON / GPX，可选全部或时间范围 |
| 更正 | 地点名称可改名；轨迹本身为自动采集，不支持手工修改 |
| 删除 | 「我的 → 数据 → 删除全部数据」（不可恢复，二次确认） |
| 撤回同意 | 「我的 → 隐私与数据 → 撤回同意并停止记录」 |
| 拒绝 | 首次启动时不勾选同意即不进入记录功能 |

撤回同意后：立即停止记录、不再请求定位、回到引导页。已记录的数据仍保存在本机，
你可以自行导出或删除。

## 五、权限说明

| 权限 | 用途 | 拒绝的后果 |
|---|---|---|
| `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` | 采集轨迹 | 无法记录（核心功能不可用） |
| `ACCESS_BACKGROUND_LOCATION` | 锁屏/切后台时继续记录 | 只在打开应用时记录 |
| `POST_NOTIFICATIONS` | 显示前台服务通知（Android 要求记录时必须可见） | 通知不可见，记录仍运行但难以感知 |
| `RECEIVE_BOOT_COMPLETED` | 开机后提醒「是否继续记录」 | 开机后需手动打开应用 |
| `INTERNET` / `ACCESS_NETWORK_STATE` / `ACCESS_WIFI_STATE` / `CHANGE_WIFI_STATE` | 地图瓦片、纠偏与地名反查；网络状态判断 | 地图无法加载，纠偏不可用 |

应用**不申请**存储权限：导入导出全部通过系统文件选择器（SAF），
只访问你明确选中的那个文件。

## 六、数据保存期限

- 轨迹数据：一直保存，直到你删除。
- 诊断日志：自动保留最近 7 天，超期自动清除；不含坐标。
- 我们没有服务器，因此不存在「服务端留存期限」。

## 七、未成年人

本应用不面向 14 周岁以下的儿童。若你是未成年人，请在监护人陪同下阅读本政策，
并在取得监护人同意后使用。

本政策更新后会修改文首的生效日期。涉及处理目的、信息类型或共享对象的重大变更时，
应用会在下次启动时重新征求你的同意。
